# Story 2.5: AI-Powered Book Discovery

## Status

Not Started

## Story

[Epic Reference: docs/epics/epic-2-ai-intelligence-user-interaction.md - Story 2.5]

**As a** reader looking to expand my reading list,
**I want** to discover new books from external sources using AI-powered web search,
**so that** I can find books that don't currently exist in my TBR queue and add them to my reading list.

## Background

This story distinguishes from Story 2.2 (Mood-Based Recommendation):
- **Story 2.2 (/recommend)**: Searches existing TBR queue for books already in the database
- **Story 2.5 (/discover)**: Searches external sources for NEW books not yet in the database

The `/discover` command will be the primary method for users to find and add new books to their TBR queue.

## Acceptance Criteria

1. System provides a `/discover` bot command that accepts natural language search queries
2. User can describe what they're looking for using free-form text (e.g., "fantasy books like Brandon Sanderson", "cozy mysteries set in small towns", "science fiction with strong AI themes")
3. System uses Gemini Flash to extract search intent and generate structured search queries
4. System performs AI-powered web search across configured recommendation sources (blogs, Goodreads lists, book aggregators)
5. System returns top 5-10 book suggestions from external sources with metadata
6. Each suggestion displays: title, author, source, brief description, and confidence score
7. Response includes inline keyboard buttons for user actions: "Add to TBR", "Tell me more", "Search similar"
8. When user selects "Add to TBR", system:
   - Searches for complete book metadata (ISBN, page count, publication date, etc.)
   - Enriches book data using existing data enrichment service (Story 1.5)
   - Saves book to database with status='to_read'
   - Returns confirmation with enriched metadata
9. If no suitable matches found, system provides helpful fallback message with suggestions
10. System handles rate limiting and API failures gracefully with appropriate user messaging

## Technical Approach

### AI Web Search Pipeline

1. **Intent Extraction** (Gemini Flash):
   - Extract key search terms, genres, themes, author comparisons
   - Generate structured search query from natural language input

2. **Multi-Source Search**:
   - Query recommendation sources from `recommendation_sources` table
   - Prioritize sources based on scope and priority fields
   - Execute parallel searches across top 3-5 sources
   - Parse and normalize results

3. **Result Ranking**:
   - Score results based on relevance to original query
   - Consider source priority and confidence
   - Deduplicate across sources
   - Return top N ranked results

4. **Metadata Enrichment** (Integration with Story 1.5):
   - When user selects a book to add, fetch complete metadata
   - Use existing `enrich-metadata` Edge Function
   - Extract genres, themes, tone, pacing, AI summary
   - Save enriched book to database

### Recommendation Sources Integration

Leverage existing `recommendation_sources` table structure:
```yaml
- name: "The StoryGraph"
  url: "https://app.thestorygraph.com"
  scope: "fiction"
  categories: ["literary-fiction", "romance", "mystery", "sci-fi", "fantasy"]
  priority: 1
```

## Notes

- **Distinction from /recommend**: This command searches EXTERNAL sources for NEW books, while /recommend searches the user's existing TBR queue
- **Recommendation sources**: Leverage existing `recommendation_sources` table from Story 1.5
- **Metadata enrichment**: Reuse existing enrichment pipeline to ensure consistency
- **Rate limiting**: Critical for external source searches to avoid bans
- **Future enhancement**: Could integrate with Google Custom Search API or other search APIs for broader coverage
