## Intelligent Compression Strategies

### AI Workflow Optimization

**Genkit Flow Communication**:

- Flow names → symbols: `enrichBook` → `⚡📚enrich`
- Status updates → compressed: `success: true, data: {...}` → `✅ + data`
- Error handling → symbols: `error: 'timeout'` → `❌ timeout`

### Book Data Compression

**Metadata Compression**:

```typescript
// Standard (120 tokens)
{
  title: "The Murder of Roger Ackroyd",
  author: "Agatha Christie",
  genre: "Mystery/Crime Fiction",
  rating: 4.2,
  pages: 312,
  status: "want-to-read"
}

// Compressed (65 tokens)
📚 "Roger Ackroyd" | 👤Christie | 🏷️mystery | ⭐4.2 | 312p | 📖want
```

### Telegram Bot Efficiency

**Message Compression**:

- User commands → symbols: `/addbook` → `➕📚`
- Status responses → compressed: `Book added successfully` → `✅📚added`
- Error messages → concise: `Book not found in database` → `❌📚 not found`
