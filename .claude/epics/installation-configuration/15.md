# Task: Container and Database Setup

## Description
Install and configure Docker for containerized development and Supabase CLI for local database management. This establishes the foundation for running PostgreSQL with pgvector extension locally and managing database schema development.

## Acceptance Criteria
- [ ] Docker Desktop installed and running on macOS
- [ ] Docker can successfully run containers (`docker run hello-world`)
- [ ] Supabase CLI installed and authenticated
- [ ] Local Supabase instance can be started and accessed
- [ ] PostgreSQL database running with pgvector extension
- [ ] Database connection verified from development tools

## Technical Details
- **Docker Installation**: Use Docker Desktop for macOS with GUI management
- **Supabase CLI**: Install via npm or direct binary download
- **Local Database**: Configure PostgreSQL 15+ with pgvector for embeddings
- **Port Configuration**: Default ports (5432 for PostgreSQL, 54323 for Supabase API)
- **Volume Management**: Persistent storage for local database data
- **Health Checks**: Verify all services start correctly and remain stable

## Dependencies
- [ ] Core development tools installed (Node.js for Supabase CLI)
- [ ] Docker Desktop compatible macOS version
- [ ] Supabase account for CLI authentication
- [ ] Available disk space (minimum 2GB for containers)

## Effort Estimate
- Size: M
- Hours: 2-3 hours
- Parallel: false (requires core tools from task 001)

## Definition of Done
- [ ] Docker Desktop installed and functional
- [ ] Supabase CLI authenticated and operational
- [ ] Local Supabase project initialized
- [ ] PostgreSQL database accessible and responding to queries
- [ ] pgvector extension enabled and tested
- [ ] Database persistence verified across container restarts
- [ ] Connection strings documented for development use
